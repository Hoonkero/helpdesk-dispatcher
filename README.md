# Диспетчер обращений: демонстрационный прототип

Python 3.11+, Flask, SQLite. Обработка демонстрационных сообщений: классификация правилами, контекст уточнений, хранение заявок, база знаний и очередь действий для оператора. Локальная LLM необязательна.

## Запуск

Создать виртуальное окружение Python, активировать его и установить Flask и pydantic-settings:

```sh
python -m venv .venv
# Linux/macOS: . .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install 'flask>=3,<4' 'pydantic-settings>=2.4,<3'
```

Создать локальный .env:

```dotenv
SAFE_MODE=true
DISPATCHER_MODE=shadow
MAX_TRANSPORT=fake
LLM_ENABLED=false
ASPIA_ENABLED=false
ASPIA_DRY_RUN=true
```

```sh
python -m app.web.app
python -m unittest discover -s tests -t .
```

29.10.2026: 55 тестов прошли. Они проверяют правила, разговоры, ограничения действий, исполнителей и веб-интерфейс. Это не испытание живого MAX или удалённых компьютеров.

## Ограничения

Адаптер app.transports.playwright_max отсутствует. Ветки playwright/sandbox при его отсутствии возвращают fake. Отдельный стенд sandbox/app.py не доказывает сквозную интеграцию. Эту версию нельзя представлять как готового бота для живого MAX.

Интерфейс предназначен для локального запуска с демонстрационными данными. Нет полноценного входа и защиты операторских действий для многопользовательского сервера; ключ сессии фиксирован в исходнике. Не публиковать этот прототип как защищённый сервис. До внедрения нужны реальный транспорт, контроль доступа, управление секретами, аудит и интеграционные испытания. Доля автоматически решённых заявок и экономия времени не измерялись.
