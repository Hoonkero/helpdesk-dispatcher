# Changelog

## v0.1.0 — 2026-09-18
Первый публичный релиз.
- Правила классификации и извлечения сущностей, база знаний в markdown
- Склейка разговора «общий чат → личка» в одну заявку
- Политика поведения: бот никогда не пишет в чат заявок, не читает приглушённые чаты, `SAFE_MODE`
- Очередь действий с одобрением оператора, режимы `shadow` / `assisted` / `auto`
- Исполнитель Aspia с белым списком сценариев, эскалация коллегам
- Веб-интерфейс оператора, стенд-клон веб-клиента MAX
- 55 тестов, из них 10 на нерушимые правила
